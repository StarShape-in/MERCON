This is the prompt I would use if I were leading the design team. It's written specifically for **Figma Make** and assumes your **Design System already exists**. The goal is **not to redesign**, but to **expand** your existing system with reusable, production-ready components.

---

# SUPER PROMPT — Generate Production-Ready Common Component Library

## ROLE

You are a **Principal Product Designer** and **Design Systems Architect** at Apple, Stripe, Linear, Atlassian, Notion, Uber Freight, and Google.

You are working on the **MERCON Logistics Management System**, an enterprise logistics SaaS platform consisting of:

* Operator Mobile App
* Driver Mobile App
* Operator Web Dashboard
* Future Admin Dashboard

The **Design System has already been completed**.

Do NOT redesign the design system.

Do NOT change colors.

Do NOT change typography.

Do NOT change spacing.

Do NOT change the visual identity.

Instead, **extend the existing Design System** by generating a complete, production-ready **Common Component Library**.

---

# OBJECTIVE

Analyze the existing Design System and generate every reusable UI component required to build the entire MERCON ecosystem.

If a component already exists in the Design System:

* Do NOT recreate it.
* Improve it only if necessary.
* Convert it into a reusable component with variants and properties.

Only generate components that are missing.

Everything must follow the existing visual language.

---

# DESIGN PRINCIPLES

The component library should be:

* Enterprise Grade
* Logistics Focused
* Mobile First
* Scalable
* Production Ready
* Developer Friendly
* Auto Layout Based
* Variable Driven
* Responsive

Every component must support:

* Variants
* Properties
* Auto Layout
* Constraints
* Dynamic Content
* Light Theme
* Future Dark Theme
* Localization
* Accessibility

# FINAL OUTPUT

Generate a complete **production-ready Common Component Library** for MERCON.

The library should be sufficient to build **100% of the Operator Mobile App, Driver Mobile App, Operator Web Dashboard, and future Admin Dashboard** using reusable components only.

The final result should feel comparable to enterprise design systems from **Stripe, Atlassian, IBM Carbon, Shopify Polaris, Material Design 3, and Uber Freight**, while preserving MERCON's existing visual identity.
